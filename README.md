# Car-Black-Box
Developed a Car Black Box System in Embedded C to record and monitor critical vehicle events for analysis and diagnostics. The system continuously captures driving events such as gear changes, speed variations, collisions, and other significant occurrences, storing them in non-volatile memory for future retrieval.

Key Features:
- Real-time vehicle event monitoring
- Event logging with timestamp information
- Gear position tracking
- Speed monitoring and recording
- Collision/crash event detection simulation
- EEPROM-based data storage
- Event history viewing and navigation
- Secure retrieval of stored logs
- Menu-driven user interface
- Efficient memory management

Technologies Used:
- Embedded C
- PIC Microcontroller
- EEPROM Interfacing
- UART Communication
- Timers and Interrupts
- Linux Development Environment
- Git & GitHub

Learning Outcomes:
- Embedded system design and development
- EEPROM interfacing and data storage
- Event-driven programming
- Serial communication using UART
- Real-time monitoring and logging
- Debugging and testing embedded applications
- Automotive safety and diagnostics concepts

This project simulates the functionality of an automotive black box by continuously recording vehicle-related events and storing them for later analysis. The system demonstrates embedded software development, data logging techniques, memory management, and automotive monitoring concepts commonly used in vehicle diagnostics and safety applications.
